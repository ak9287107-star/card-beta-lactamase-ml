# Data and provenance

CARD-derived sequence data are not redistributed in this repository. Obtain the appropriate release directly from the official CARD website and review the current terms of use before downloading or sharing any derived data.

The preprocessing script expects a CSV with a protein-sequence column named `sequence`, `protein_sequence`, `aa_sequence`, or `seq`. Annotation columns such as `card_short_name`, `aro_name`, `drug_classes`, `amr_gene_family`, or `gene_family` are used when present.

For a reproducible run, record:

- CARD release identifier;
- download URL;
- download date;
- archive checksum;
- filters applied;
- sequence deduplication rule; and
- the exact command used to generate the modeling table.

The labels generated by this repository are exploratory CARD drug-class spectrum proxies. They do not constitute direct experimental hydrolysis, MIC, kinetic, or clinical-resistance measurements.
