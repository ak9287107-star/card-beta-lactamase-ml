# Manuscript-support files

This directory contains the anonymous manuscript draft used for the reproducibility release, its numbered bibliography, and supporting derived results.

The title page, cover letter, reviewer suggestions, and correspondence are intentionally not included in this public repository.

The manuscript reports CARD-derived drug-class spectrum proxies rather than experimentally validated hydrolysis or clinical resistance phenotypes. Raw CARD sequence data are not redistributed. Users should obtain the appropriate CARD release directly from CARD and review its current terms of use.

The included Word document is the anonymous manuscript file prepared for review. The GitHub release tag identifies the exact code and supporting files associated with this version.
